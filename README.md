\# Farm-to-Table Platform



A Java-based desktop application designed to simulate a multi-enterprise farm-to-table supply chain system, connecting producers, distributors, inspectors, and retailers.



\## Features

\- Multi-role system across Farm, Inspection, Distribution, and Retail workflows

\- Modular architecture using OOP principles

\- UI built with Java Swing

\- Business workflow simulation across multiple stakeholders



\## Technologies

\- Java

\- Swing (UI)

\- Maven



\## Purpose

This project demonstrates:

\- Technical development capability

\- Object-oriented design and modular system architecture

\- End-to-end workflow implementation across multiple business roles
